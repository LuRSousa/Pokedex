## Pokédex
Este projeto é uma Pokédex interativa desenvolvida para consolidar conceitos de manipulação de DOM com JavaScript. O objetivo principal foi colocar em prática o consumo de APIs externas.

### Tecnologias
- **JavaScript**
- **HTML5, CSS3 e SCSS**
- **PokeAPI**

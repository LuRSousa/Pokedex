## Pokédex Interativa
Este projeto é uma Pokédex dinâmica desenvolvida para consolidar conceitos avançados de manipulação de DOM e integração com serviços externos. O foco principal foi criar uma interface fluida que consome dados em tempo real sobre o universo Pokémon.

### Tecnologias e Conceitos
* **JavaScript (ES6+):** Lógica de busca e renderização dinâmica.
* **API REST:** Consumo de dados assíncronos via **PokeAPI** utilizando `fetch` e `Async/Await`.
* **CSS3 & SCSS:** Estilização moderna com foco em componentes reaproveitáveis.
* **HTML5:** Estruturação semântica para melhor acessibilidade.

### Funcionalidades
* **Consumo de API:** Requisições em tempo real para buscar estatísticas, tipos e imagens de cada Pokémon.
* **Filtro de Busca:** Localização instantânea por nome ou número do ID.
* **Manipulação de DOM:** Atualização dinâmica da interface sem necessidade de recarregar a página.
